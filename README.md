This is a simple Spend Tracker project created as part of my learning and academic practice.
The main goal of this project is to understand how a basic full-stack application works, including frontend, backend, and database interaction.

The Spend Tracker helps users:
Add daily expenses
View expense records
Manage spending data in a simple way

This project is built to improve my understanding of real-world application structure and full-stack development concepts.

Tech Stack Used
Frontend: React
Backend: Node.js, Express
Database: MongoDB
Tools: VS Code, Git, GitHub

Project Structure
Spend-Tracker/
│
├── client/        # Frontend code
├── server/        # Backend code
├── package.json
├── package-lock.json
└── .gitignore

How to Run the Project Locally

Clone the repository
git clone https://github.com/Nandita-Singh1/Spend-Tracker.git


Go to the project folder
cd Spend-Tracker


Install dependencies
npm install


Start the server
npm start


(Frontend and backend can be run separately if required.)
